# FakePay 1.21.1

Fabric client mod for Minecraft 1.21.1.

- Real `/pay <player> <amount>` is the default.
- `/fakepay toggle` enables/disables fake-pay mode.
- In fake mode, `/pay` is intercepted locally and does not reach the server.
- F4 opens a client-side fake balance editor.

The fake balance is local-only and never changes the DonutSMP/server balance.
